Punnett Square Generator

Visualize genetic inheritance patterns with this interactive Punnett square tool. Perfect for students, teachers, and genetics enthusiasts.

How to Use This Tool

  1. Enter the number of genetic traits (1-7)
  2. Enter all possible allele combinations for each parent, separated by commas
  3. Click "Generate Punnett Square" to visualize the possible offspring combinations
  4. Each unique genotype combination will be color-coded for easy identification
For monohybrid cross: 1, dihybrid: 2, etc.
Enter all possible combinations (2^n where n is number of traits)
